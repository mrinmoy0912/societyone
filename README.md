# IIM Calcutta (IIMC) Official Homepage Portal

A modern, responsive, production-ready single-page website for the **Indian Institute of Management Calcutta (IIM Calcutta)** built with React, Vite, TypeScript, and Tailwind CSS.

## Features

- **Official Branding**: Designed in compliance with IIM Calcutta's prestige using signature green (`#1f5d08`), gold, and navy color palettes.
- **Responsive Navigation**: Sticky header with dropdown menus for About, Programmes, Academics, Campus Life, and News.
- **Hero Slider**: Dynamic hero section showcasing institute milestones and campus imagery.
- **About Section**: Comprehensive overview of Asia's finest business school.
- **Academic Programmes**: Interactive tabbed display for MBA (PGP), MBAEX (Executive), PGPDBA, and Doctoral Fellow programmes.
- **Academic Records & Resources**: Statistics, student handbook downloads, and AMS portal quick links.
- **Campus Life**: Exploration of the 135-acre Joka campus, sports complex, student clubs, and library.
- **News & Announcements**: Filterable news articles and upcoming executive lecture series.
- **Footer**: Complete contact information, social links, and quick navigation.

## Setup Instructions

1. **Clone or Download** the project repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
